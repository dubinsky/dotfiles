# Unofficial Grok Bot on system upgrade

`omarchy update` and pacman do not upgrade Grok Bot. When Leonid asks to
upgrade or update the system (or to run `omarchy update`), also upgrade the
unofficial AppImage if it is present on this machine.

Skip if `~/Applications/GrokBot-current.AppImage` is missing.

Inventory and the update commands: `~/Podval/dub.podval.org/notes/SystemAdministration/Omarchy.md` (Grok Bot). In-app **Check for Updates** is not a Linux updater.

This is not Grok Build (`grok`). The desktop app command is `grok-bot`.
